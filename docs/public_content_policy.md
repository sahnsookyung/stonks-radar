# Public Content Policy

Public copy must preserve uncertainty, freshness, delay labels, source strength, and correction status.

Allowed terms:

- scenario basket
- model watchlist
- thematic exposure
- risk factors to monitor
- illustrative weights with methodology

Forbidden public copy:

- buy now
- sell now
- guaranteed upside
- personalized allocation
- portfolio optimization based on user circumstances
- brokerage connection
- automated trade execution
