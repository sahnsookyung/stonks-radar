# Source Policy

Preferred source order:

1. official APIs and machine-readable data
2. official agency, central-bank, exchange, and issuer pages
3. filings and company IR
4. reputable RSS/news metadata
5. aggregators as discovery only
6. public web factual extraction
7. manual estimates and private notes for private research

Retention defaults:

- metadata-only for restricted/news discovery
- structured-fact-only for official facts
- excerpt-only for review where allowed
- full-text-open only for public-domain/open official material
- full-text-private only for explicit private clips/files

Public snapshots never expose restricted raw prose or private clips.
